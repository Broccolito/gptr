## Task 1 - Block grammar, hashes and rendering

**Precheck.** Task 1 calls only P01 helpers, all present in `R/`: `as_utf8()`
(`utils-encoding.R`), `hash_sha256()` (`utils-hash.R`) and `` `%||%` `` (`aaa-state.R`). No other

`tests/` before this task. `tests/testthat/helper-arch.R` already registers `doc-blocks.R` as L4
(P15).

**Built.** `R/doc-blocks.R` (new, part 1 of 4):
- The marker regexes `doc_re_open`, `doc_re_close` and `doc_re_kv` are the contract 11.5 grammar
  verbatim. `doc_re_steer` matches `## Steer:`/`## Follow-up:` lines. Also added: the body
  placeholder `doc_block_token` (`"@@GPTR_BLOCK@@"`), `doc_header_keys` in contract order, and
  `doc_quoted_keys` (`children`).
- `doc_one_line()` and `doc_str_literal()` are text helpers. `doc_str_literal()` writes an R
  string literal that keeps non-ASCII characters.
- `doc_parse_kv()` returns a named list of strings. Quoted values are decoded by
  `doc_str_unquote()` (review round 1), not by the R parser.
- `doc_format_kv()` writes keys in contract order, with unknown keys last.
- `doc_find_blocks()` returns a data frame (`id`, `start`, `end`, `indent`, and the list column
  `header`). Its `malformed` attribute flags unterminated, nested, orphan or duplicate markers.
  Only lines that contain `gptr:` are tested against the patterns.
- `doc_block_body()` returns a block's body with its indentation removed.
- `doc_body_sha()` is the first 8 hex of the body's sha256, ignoring steer and follow-up lines
  (IC-49).
- `prompt_hash()` is 12 hex: trimws, CRLF -> LF, whitespace around newlines removed.
- `args_hash()` is 8 hex of the radix-sorted `name=value` pairs, or `NULL` without interpolation.
  It accepts P08's character vector of pairs or a named list (IC-45).
- `doc_block_status()` returns one of undone > user-edited > stale (prompt or args) > fresh.
- `doc_render_block()`, `doc_indent_lines()` and `doc_splice()` render and splice blocks.

`tests/testthat/test-doc-blocks.R` is new (part 1 of 4), with the plan's five tests.

**Adaptations (the contract is unchanged; recorded in `dev/DEVIATIONS.md` D-062 with the
review-round-1 changes):**
1. **Header values with a line break are quoted.** The plan's literal `doc_format_kv()` quoted only
   values holding a blank, tab, quote, `=` or backslash. A value holding a CR or LF (for example a
   non-syntactic `gptr_return()` name in `value=`, or a child name in `children=`) would then be
   written unquoted and split the marker line. That breaks `BLOCK_OPEN`, which is a single-line
   pattern. The quote class is now `[ \t\r\n"=\\]`, and `doc_str_literal()` already escapes
   `\n`/`\r`. Contract 11.5 says only that values containing spaces are quoted, so quoting more
   values is compatible with it.
   - Two expectations were added to the first test: the formatted header has no newline, and the
     value round-trips through `doc_parse_kv()`.
   - The plan literal fails the first one: its quote test returns `FALSE` for `"a\nb"`
     (`dev/.validation/P15/task1-red-newline.log`).
   - The long `if` line was split over two lines, to stay within 100 characters.
2. **IC-74 guard.** One expectation was added: a local Ollama model tag (`ollama/qwen3:8b`) is
   formatted unquoted and unchanged, so local model provenance in `model=` survives (07 section 6,
   P15 row). The grammar itself needed no change. Digest and image provenance have no header
   shape in Task 1; they are applied in the later tasks that define those records (block content,
   S2 records, System 1 one-line blocks).

**Review round 1** (`changes_required`: 1 major, 1 minor, 1 nit; all three fixed):
1. **Major: quoted values were decoded with `str2lang()`.** In a C locale the R parser rewrites
   each non-ASCII character of a literal as `<U+00E1>`, so the always-quoted `children=` (and any
   quoted `value=`) lost its non-ASCII characters; Task 5 would write the damage back into the
   document. Confirmed: the reviewer's C-locale case fails on the round-0 source. The new
   `doc_str_unquote()` decodes exactly the escapes `doc_str_literal()` writes (backslash, quote,
   `\n`, `\r`, `\t`); any other escaped character stands for itself; text that is not one whole
   quoted literal is kept as written (as `str2lang()`'s error branch did). A 250,000-character
   quoted value decodes in 0.05 s (scratch probe).
2. **Minor: no D-entry.** Added D-062 (line-break quoting, parser-free decoding, exact key
   lookups, the IC-74 model-tag guard, and the PASS count); adaptation 1 points at it.
3. **Nit: `$` partial matching in `doc_block_status()`.** It now reads `header[["status"]]`,
   `[["sha"]]`, `[["prompt"]]` and `[["args"]]`.
