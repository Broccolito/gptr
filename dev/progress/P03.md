the package redaction hook. Actual baseline red `auth-redact`:
FAIL 13/WARN 0/SKIP 0/PASS 3; baseline green: PASS 78.

Additional safety evidence and corrections:

- Generic fields named signature/json and replay-shaped objects inside
  arguments/details bypassed redaction. Added paired replay-preservation and
  ordinary-payload canaries first: FAIL 12/PASS 81. Exemptions now require the
  matching replay block field and are disabled recursively for ordinary input,

- Unterminated PEM left its last line, and scalar truncated PEM was unchanged.
  Regression FAIL 2/PASS 94. Every remaining line is now removed; a suffix is

- A registered value equal to its marker name made repeated passes nest markers.
  Regression FAIL 4/PASS 98 (four warnings came only from waldo rendering the
  invalid-byte failing comparison). Literal replacement now protects complete

  Adjacent raw credentials and malformed marker prefixes remain redacted.

  FAIL 4/PASS 104. Only complete known markers/displays or the exact marker for
  the sensitive key are exempt. An unknown marker containing a credential also
