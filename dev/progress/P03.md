the package redaction hook. Actual baseline red `auth-redact`:
FAIL 13/WARN 0/SKIP 0/PASS 3; baseline green: PASS 78.

Additional safety evidence and corrections:

- Generic fields named signature/json and replay-shaped objects inside
  arguments/details bypassed redaction. Added paired replay-preservation and
  ordinary-payload canaries first: FAIL 12/PASS 81. Exemptions now require the
  matching replay block field and are disabled recursively for ordinary input,
  argument, metadata, header, settings and environment fields; green PASS 93.
- Unterminated PEM left its last line, and scalar truncated PEM was unchanged.
  Regression FAIL 2/PASS 94. Every remaining line is now removed; a suffix is
  preserved only after a real END delimiter; green PASS 96.
- A registered value equal to its marker name made repeated passes nest markers.
  Regression FAIL 4/PASS 98 (four warnings came only from waldo rendering the
  invalid-byte failing comparison). Literal replacement now protects complete
  known vault/rule markers and retains bytewise behavior for invalid UTF-8.
  Adjacent raw credentials and malformed marker prefixes remain redacted.
- Structural redaction's prefix exemption exposed password tails. Regression
  FAIL 4/PASS 104. Only complete known markers/displays or the exact marker for
  the sensitive key are exempt. An unknown marker containing a credential also
  failed its added negative control (combined FAIL 5/PASS 105), then was fixed.

## Task 3 — streaming redaction

Added the streaming redactor, bounded holding logic and UTF-8 chunk handling.
Task red `auth-redact`: FAIL 5/WARN 0/SKIP 0/PASS 110. Literal-plan baseline
passed 130 assertions, including 1,600 generated streaming documents.

D-010 closes the plan's unsafe overflow residual: holding an unresolved
candidate above the configured cap now raises `gptr_error_redaction_limit` with
only a generic message and the numeric limit. The stream clears pending/last
text and permanently rejects later push/flush calls. Flush independently checks
its buffer. Invalid-byte overflow uses the same fail-closed path. Within the
supported bound, chunk/whole-text parity remains required; overflow is the
explicit documented exception rather than raw-prefix emission.

marker corruption across chunks. Regressions cover every split immediately
around the default cap, split derived credentials, unterminated PEM, direct
flush overflow, invalid bytes, safe condition metadata, no emitted prefix,
cleared buffers, latched failure, and positive finite integer limit validation.
