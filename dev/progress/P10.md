## Task 3 - Unified diffs

**Precheck.** Task 3 calls only P01 functions, all present in `R/`: `check_strings()`,
`check_string()` and `check_number()` (`utils-conditions.R`), `est_tokens()` (`utils-tokens.R`),
`as_utf8()` and `utf8_mark()` (`utils-encoding.R`). The tests use `withr` and, for the
`git apply` checks, a `git` binary on `PATH` (`/usr/bin/git`, 2.50.1). Nothing from P06-P09 is
called.

**Built.** `R/tool-diff.R` (new; architecture "L4", consumed by Task 6, P15 and P16):
`diff_lis()` (O(n log n) LIS; review round 1), `diff_snake()`, `diff_myers()` and
`diff_myers_back()` (Myers O(ND) capped at D = 256; a gap beyond the cap is reported as
replaced), `diff_match()` (prefix/suffix trim, then patience anchors, then Myers on the gaps),
`diff_ops()` (the edit script `data.frame(op, a, b)` in file order), `diff_hunks()` (GNU unified
hunks, a count of 1 written without `,1`, `\ No newline at end of file`), `diff_budget()`,
`diff_lines()` (04 section 7.10 signature), `diff_split()` and `diff_unified()` (`--- a/` /
`+++ b/` headers). `tests/testthat/test-tool-diff.R` is new: the plan's 6 blocks verbatim plus 9
added blocks (149 expectations; 2 of the blocks, with 13 expectations, came with review round
1). No export, so no document action and no `NAMESPACE`/`man/` change.

**Adaptations (recorded as D-046 in `dev/DEVIATIONS.md`; outputs are unchanged wherever the
plan-literal source worked):**
1. **The no-newline sentinel could collide.** The plan keyed a last line lacking its newline as
   `paste0(line, "\001<no-eol>")`. A line that has its newline and ends in that text then matched,
   and `diff_unified("f", "x\001<no-eol>\n", "x")` returned `character()`, which claims the texts
   are equal. Lines are now compared as integer codes, and a last line without its newline gets
   the negated code, which no other line can share.
2. **`diff_unified()` validates its arguments** (`path` one non-empty string, `old`/`new` one
   string each and possibly empty, `context` a whole number >= 0) with
   `gptr_error_invalid_argument`. The plan rendered an `NA` text as `-NA` and stopped on a
   vector with base R's "the condition has length > 1".
3. **`context` is clamped to the edit script's length.** Near `.Machine$integer.max`, the plan's
   `2L * context + 1L` overflowed (a warning, then base R's "NA/NaN argument"). A context wider
   than the script shows everything either way, so the output is the same.
4. **Myers memory is O(D^2).** The plan kept a full copy of `v` (2(n + m) + 5 integers) for each
   of up to 257 rounds. A 100,000-line total rewrite grew the heap by 401.8 MB (measured), and
   1,000,000 lines would have needed about 4 GB. Now `v` spans diagonals -(D + 1) .. D + 1 and each
   round keeps only its window -d .. d. Also, `diff_myers_back()` loops over `rev(seq_len(d))`:
