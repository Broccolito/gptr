**Adaptations (reconciled with the real interfaces and the contract; D-072).**
1. `res_session_id()` delegates to P02's `ext_session_id()` and `res_inside()` to P01's
   `path_inside()`: the same rules already exist in L0, so the plan's copies were not duplicated.
2. `plugin_type_paths()` also accepts an array for a gptr manifest's `skills`/`prompts`/`agents`
   key: P01's `json_decode()` (contract section 6, `simplifyVector = FALSE`) turns a JSON array
   into a list, which the plan's `is.character(v)` test silently replaced by the default
   directory. Escaping entries still give the `a path outside the plugin was ignored` diagnostic.
3. `rdepends_missing()` reports an entry whose version cannot be parsed (`stats (>= 1.)`) as
   missing instead of throwing (manifest problems are diagnostics, never errors).
4. `res_match()` ignores `NA` candidates (subsetting with `which()`) and de-duplicates an exact
   hit; `res_register()` skips `NULL` specs (what `res_spec()` returns for an invalid one).
The test file shadows P10's package-level `write_file(path, content)` with the plan's local
`write_file(path, lines)` helper inside the test file only (later P17 tasks extend this file and
use it); package code is unaffected.
