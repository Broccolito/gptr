### Audit scenarios A-I (gptr 8d9a388)
Harness: terminal R in a processx pty, 80 columns, TERM=xterm-256color, `peter(mode = "manual")` on a fake
provider. Request 1 streams about 2.5 s of text, then calls r `zz = 1`, which asks (E and F: request 1 runs a
read-only tool that blocks R for 3 s, request 2 asks; H: request 1 asks an ask-tool question). Later requests
echo `REQ<n> roles=...`. Every ask showed the call twice: `● r  zz = 1`, then `r  zz = 1` above the question.

| Scenario | What was typed | Key screen line | REQ roles | Outcome |
|---|---|---|---|---|
| A | `steer me` + Enter while streaming | `[gptr] steering: 'steer me'; it reaches the agent at its next step` | REQ2 `user,assistant,tool_result,operator` (the relay) | works |
| B | `use base R`, no Enter, then the ask | `allow? [y]es / [a]lways / [n]o / [?]: use base R`; Enter gives `Not an answer: 'use base R'. Type y, a, n (n <text> says what to do instead) o` / `r ? for details.` | REQ2 `user,assistant,tool_result` | text lost, mid-word wrap |
| C | `no wait, plot it first`, no Enter | `allow? ...: no wait, plot it first`; Enter gives `error: Permission denied: wait, plot it first. ...` | REQ2 `user,assistant,tool_result`, last = the denial | becomes a denial |
| D | `steer me` + Enter just as the ask is drawn | `allow? ...: steer me`, then the question again | REQ2 `user,assistant,tool_result` | line discarded (stale rule) |
| E | `steer me` + Enter while the tool blocks R | the steering notice after `done (3.0 s)` | REQ3 `user,assistant,tool_result,operator,assistant,tool_result` | reached REQ2, by timing (Task 7 makes it certain) |
| F | `and also`, no Enter, while the tool blocks R | `allow? ...: and also`; `Not an answer: 'and also'. ...` runs to column 80, the rest at column 0 | REQ3 `user,assistant,tool_result,assistant,tool_result` | text lost |
| G | `use base R`, no Enter, then Ctrl-C | `[gptr] paused sc762fa45e0: [s]teer, [f]ollow-up, [c]ontinue, [a]bort,`; the menu's `? ` starts empty | REQ2 `user,assistant,tool_result,operator` after retyping at `steer>` | draft lost (SIGINT flush) |
| H | `use base R`, no Enter, at the ask-tool question | `Choose (a number; or type your own answer): use base R` | REQ2 `user,assistant,tool_result`, last `The user answered: - q1: (typed) use base R` | becomes the answer |
| I | `use base R`, no Enter, as the run ends | `peter> use base R` at the next prompt; Enter sends it | REQ2 `user,assistant,user`, last `use base R` | works |

Root cause of B, C, F and H: during a run the terminal is canonical with echo off and the partial line waits in
the kernel buffer; the question's `readline()` leaves canonical mode, inherits it, shows it after the prompt and
takes it as the answer.
