## Task 3 — Retry classification, date parsing and backoff

- Actual initial red: FAIL 8 / PASS 0. Baseline implementation with real P03
  redaction and Task 2 URL parsing passed 63 assertions, including the German
  locale and RNG-state checks.
- Boundary regressions first produced FAIL 26 / WARN 2 / PASS 69, exposing
  invalid timezone offsets, negative/nonfinite delays, unchecked retry caps,
  integer overflow in attempts, overly broad 5xx classification, unrelated body
  text triggering a spend-cap exception, and malformed nested header values.
- Corrections preserve finite timing, clamp the exponent before arithmetic,
  recognize spend-cap information only in named error code/type fields and
  limit HTTP server-error retries to 500–599. Malformed header values fall back
  to ordinary bounded backoff. A NUL-body regression confirms the existing
  decoder keeps the transport error rather than leaking raw error-body text.
- Current focused result: FAIL 0 / WARN 0 / SKIP 0 / PASS 95; both files lint
  clean. Independent final review and 14 source-only boundary probes passed.
- Raw logs: ignored `dev/.validation/P04/T03-*.log`. No provider/network calls.
