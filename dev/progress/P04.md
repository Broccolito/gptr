## Task 1 — SSE and NDJSON splitters

- Implemented byte-level line/end-event handling, UTF-8 marking, split BOMs,
  CR/LF variants, multiline data, duplicate fields and incomplete tails.
- Red filter `http-sse`: FAIL 9, WARN 0, SKIP 0, PASS 0 (missing splitters).
- Initial green: FAIL 0, WARN 0, SKIP 0, PASS 62, including byte-by-byte and
  randomized rechunking and 20,000 decoded deltas within the one-second CPU gate.
- Independent review caught silent NUL removal and invalid retry handling.
  New regressions first failed: FAIL 4, WARN 0, SKIP 0, PASS 62.
- Final green: FAIL 0, WARN 0, SKIP 0, PASS 70. Both source and tests are
  lint-clean under the current toolchain, and review accepted the corrections.
- D-007 records the R-string representation limitation. Retry behavior follows
  the [HTML event-stream interpretation rules](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation).
- Commit: `feat(http): add byte-level SSE and NDJSON stream splitters`.

This splitter task alone makes no HTTP requests. Separate reviewed lanes now
provide process supervision and the job table (Tasks 4–5;
[P04-processes.md](P04-processes.md)) and the reactor core (Task 6;
[P04-reactor.md](P04-reactor.md)). Full transport integration remains pending.

- Initial actual red: FAIL 3 / PASS 0. The literal implementation passed 14
  assertions while the real P03 vault dependency was absent. No stand-in was
  introduced. Full tests resumed after the actual vault became available.
- Added authority/header/timeout/request boundary regressions: actual FAIL 34 /
  PASS 24, then green 58 after implementation and one regex correction.
- Origins now use `curl::curl_parse_url()` (available since the declared minimum

  with transport behavior, including local IPv4 and IPv6 normalization. P03's
  origin binding was independently aligned to the same parser. No network I/O

  PASS 58. Exact field lookup and `nobody = 1L` for HEAD produced final
  **FAIL 0 / WARN 0 / SKIP 0 / PASS 64**. Both files are lint-clean; independent
  review accepted the final code.

  process lane, then `devtools::test(filter = "http-request",
  stop_on_failure = TRUE)`. Raw logs: ignored `dev/.validation/P04/T02-*.log`.
