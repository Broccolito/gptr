minor is cross-plan and needs no Task 3 change:

- Minor (fixed): `preset_tools()` passed arguments to a preset's `tools` function by name, while
  P02's `kind_check_preset()` only checks a positional call `f(human, model)`. A plugin preset

  third formal gets `mode` as its third positional argument, as in contract 10.2's
  `function(human, model, mode)` and P11's `tools(human, model, mode)`. A two-argument (IC-69)
  function does not get it. The reviewer's suggested fix passed `mode = mode` by name to a
  `...` function. A scratch check showed that a named `mode` partially matches the formal
  `model` (R matches partial tags before positions), so `model` received "manual" and the dots
  got the model. The positional rule avoids this.
- Minor (fixed, tests only): no expectation depended on the IC-73 provider prior. Added
  `haiku 3500 -> FALSE` (3500 x 1.35 = 4725 > 4096) and a Gemini record (`google/gemini-3-flash`,
