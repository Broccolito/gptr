Agents in your R session with gptr :: CHEATSHEET

peter() runs language model agents in your current R session, on objects already in memory. The name honors Peter Naur's work on readable language definitions and Peter Cathcart Wason's research with Jonathan Evans on reasoning. In Naur's spirit, gptr records sessions as runnable documents.

How it works

gptr_describe(mtcars)
What a model is shown of an object.
peter("Say hello.", .opts = list(context = "none"))
Workspace/object descriptions off; prompts, instructions and environment details still go.

Set up

OpenAI for live calls; Try it offline needs no key and defines fake and s for page 2.

pak::pak("Broccolito/gptr@main") library(gptr)
R 4.2+; first install pak with install.packages("pak") if needed.
gptr_login("openai")
Interactive R: enter your OpenAI key, masked.
gptr_providers(); gptr_models("gpt")
List the routes; search the offline model catalog.
gptr_config(model = "gpt", .scope = "user")
Save a default model (session, project or user).
gptr_init(".")
Create .gptr/; keep sessions and records.
gptr_trust(".", trust = TRUE)
Trust the project's settings, skills and plugins.
e = gptr_config()$egress e$openai = "ack" gptr_config(egress = e, .scope = "user")
Consent to OpenAI context in scripts.

Try it offline

step = list(tool = "r", input = list( code = "fit = lm(mpg ~ wt, mtcars)")) fake = gptr_fake_provider( list(step, "Done.")) s = peter("Fit mpg on wt.", mtcars, model = fake, mode = "auto"); coef(fit)
After library(gptr): no key or network. The scripted replies fit the model, then set s$text to “Done.”

Ask Peter from R

Live calls follow Set up. mtcars is built in; quoted model names are strings. In functions use envir = new.env() to keep objects.

fit_s = peter("Fit mpg ~ wt as fit.", mtcars, mode = "auto")
Prompt, then data. auto permits ordinary changes in scripts; critical actions still ask.
fit_s$text; fit_s$value; fit_s$turns
Answer, newest gptr_return() value (else NULL), prompt count.
peter("Summarize.", mtcars, budget = list(tokens = 5e4, turns = 5))
Per-call limits; turns counts model requests.

Pipe: one session, many turns

fit_s |> peter("Plot the residuals.")
Continue the live fit above, with its workspace.
fit_s |> peter("Check the fit.", model = "gpt:high")
Change reasoning; keep the history.
b = gptr_fork(fit_s) b |> peter("Try a log model.")
Branch; reference-object edits can reach the original.
fit_s; summary(fit_s); gptr_last()
Answer, history, most recent session.

The console

While an answer runs

In a terminal (not Windows) type, then Enter steers and Tab follows up. Ctrl-C (RStudio: Esc) pauses: [s]teer, [f]ollow-up, [c]ontinue, [a]bort, [b]ackground. Approvals: [y]es, [a]lways (session), [p] always (project), [n]o (n <text> says what to do instead).

System 1 and System 2

System 1: typed decisions

gptr_login("typesafe") # interactive R e = gptr_config()$egress e$typesafe = "ack" gptr_config(egress = e, .scope = "user")
Jev uses its own TypeSafe key and consent.
abstracts = c("Randomized trial.", "Observational study.") rct = peter("Is this an RCT?", abstracts, model = "jev")
Logical: TRUE when P(yes) ≥ 0.5 (the default threshold).
gptr_prob(rct) abstracts[rct]; sum(rct)
P(yes); subset and count these typed answers.
peter("Which tissue?", "Hepatocyte", model = "jev", choices = c("liver", "lung", "other"))
One label per input.
peter("How severe?", "Pain limits walking.", model = "jev", levels = c("low", "mid", "high"))
A fractional score: the expected 0-based level.
peter("Is this an RCT?", abstracts, model = "jev", min_confidence = 0.8)
Below the minimum (|2p−1| for yes/no), return NA or what uncertain says.
fit_s |> peter("Did it succeed?", model = "jev")
Judge the live fit's last answer; add no turn.

System 2: agents

peter("Plan an mpg analysis.", mtcars, model = "gpt", .opts = list(thinking = "high"))
Reasoning depends on the model; a suffix such as gpt:high works too.

Record, replay and export

R console, in order: use a new writable project and page 1's fake. Leave GPTR_REPLAY unset for this first recording.

gptr_register( gptr_fake_provider(fake$script))
Reset/register the offline model.
writeLines("library(gptr)", "analysis.R") gptr_doc("analysis.R") s = peter("Fit mpg on wt.", mtcars, model = "fake/fake-1", mode = "auto") gptr_doc(FALSE)
Create, bind, record a top-level call, then unbind.
gptr_source("analysis.R", replay = "replay") gptr_blocks("analysis.R")
Replay; list fresh/stale/edited/undone blocks.
GPTR_REPLAY=replay Rscript analysis.R
POSIX shell (macOS/Linux), after recording. No model calls.
gptr_export("analysis.R", "plain.R")
Code runs; peter calls become comments. Needs fresh blocks and literal arguments.
gptr_export("analysis.R", "peter.R", format = "peter")
Calls run; code is commented. Live runs need the provider.
gptr_doc("report.Rmd")
Existing report: bind in setup before calls; rmarkdown/Pandoc renders it. Quarto needs its CLI.
gptr_doc("analysis.ipynb", sync = TRUE)
Existing recorded notebook: close before syncing.

Replay needs the code's inputs/packages; cached text needs .gptr/. Top-level gptr_coach() replays too.

Tools, files and artifacts

In a new writable project. Presets: minimal, standard, readonly (r can write), extended; select with tools = "extended".

Create the fixture; read, search and list.
peter$edit("R/fit.R", list(list( oldText = "n=10", newText = "n=20"))) peter$write("notes.txt", "done\n")
Edit the fixture; write files atomically.
peter$sh(c("Rscript", "--version")) peter$bg(c("Rscript", "--version"))

Teams, fan-outs, background

Needs page 1's model setup. Modes inherit; a team throws only if all children fail. Inspect statuses.

team = peter("Review mtcars.", mtcars, agents = list( stats = gptr_agent(system = "Stats"), code = gptr_agent(system = "Code")), mode = "auto")
Named roles; team$stats$text reads one.
fan = peter("Count rows; gptr_return().", list(mtcars, iris), parallel = 2, mode = "auto")
One child per element; values in fan$value. gptr_parallel(): unrecorded calls; use separate envir values.
bg = peter("Count rows.", mtcars, background = TRUE, mode = "auto") gptr_wait(bg)
Experimental; wait finishes the run.
gptr_usage(team, by = "agent")
Usage by session/agent/model/route.

Tailor and coach a harness

Page 1 model setup required. Coaching runs unattended R processes; most tasks need auto.

h = gptr_tailor(peter, mode = "auto", coaching = list(note = "Give units."))
A call's arguments win; its tools add.
h = gptr_tailor(h, rules = list(never = list(list(rule = "r(fn:stepAIC)", why = "No stepwise selection."))))
Hard never rule; require requests a missing step.
h("Describe mtcars.", mtcars)$text
Call like peter, pipes included.
x = c(1, 2, 3) q = "Mean x; gptr_return() it." h = gptr_coach(q, x, harness = h, check=function(r) isTRUE(r$value==2))
Kept only if acceptance checks pass. Optional coach = "claude_code" needs its CLI login.
saveRDS(h, "h.rds") h = gptr_tailor(readRDS("h.rds"))
Rebuild a saved harness; checks it and shows fixed code.
gptr_tailor(h, dir = "my-harness")
Write a new Markdown output folder; gptr never reads it back.
