# gptr logo

Default: light (`logo.*`). Dark: `logo-dark.*`.

Files
- logo.svg / logo-dark.svg: vector, font embedded (IBM Plex Mono 600)
- logo.png / logo-dark.png: 518 × 600 px, hex sticker standard 4.39 × 5.08 cm at 300 dpi
- logo-2x.png / logo-dark-2x.png: 1036 × 1200 px
- logo-small.png / logo-dark-small.png: 120 × 139 px for README headers

Colors
- Ink #1c1e22, light fill #f3f1ec
- Fast model (short cursor) #b85450
- Deep model (tall cursor) #6c8ebf
- Dark version: ink fill #1c1e22, light chevron/name #efede7, deep #7d9dcb

R package use: copy logo.png to man/figures/logo.png, then add to README.md:
<img src="man/figures/logo.png" align="right" height="139" alt="gptr logo" />
